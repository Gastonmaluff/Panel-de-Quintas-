# QuintaFlow

Web app premium para quintas, casas de eventos y espacios privados de alquiler.

## Stack

- React + Vite
- Firebase Authentication
- Firestore
- Firebase Storage
- Firebase Hosting compatible con deploy estático

## Rutas iniciales

- `/`
- `/quinta/paraiso-escondido`
- `/admin`
- `/admin/reservas`
- `/admin/calendario`
- `/admin/precios`
- `/admin/configuracion`

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
