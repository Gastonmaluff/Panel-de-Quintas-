# Branding Assets

Estos PNG salen del logo oficial `logoparaisoescondido.png`. No son versiones redibujadas:
solo se recortaron areas transparentes y, para el header, se armo una composicion compacta
con pixeles del mismo archivo oficial.

- `logo-official-source.png`: archivo oficial original recibido.
- `logo-official-stacked.png`: logo completo para el hero.
- `logo-official-horizontal.png`: variante compacta para el header sticky.
- `logo-official-mark.png`: isotipo oficial para favicon, loaders o usos compactos.
